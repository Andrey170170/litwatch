From general to fine. Each round asks a few questions with variants side by side; the answers fix that level before the next one starts. Phone pages are meant to be opened on the phone.

  1. Shell: where navigation lives, how screens divide space. desktop · phone
  2. Digest: History, a day, a digest; how far each level opens in place.
  3. Topic page and Papers: the table, filters, sorting, what a row shows.
  4. Paper page: Brief, Deep card, prior work and neighbours.
  5. Look: type, density, rarity palette, badges, light and dark.
  6. Interactions: hover, press, sheets, reactions, transitions.
